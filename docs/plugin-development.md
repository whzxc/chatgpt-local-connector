# Plugin development

Develop plugins in their own repositories:

- [Usage source and development guide](https://github.com/whzxc/chatgpt-usage-plugin)
- [Kanban source and development guide](https://github.com/whzxc/chatgpt-kanban-plugin)

Connector no longer bundles plugin UI, native plugin entrypoints, plugin packaging or marketplace synchronization. Its frontend and native build commands only build the Connector product.
